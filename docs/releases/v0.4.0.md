# SearchDBPad v0.4.0 · 多引擎架构基线

SearchDBPad 0.4.0 将现有 Elasticsearch 客户端扩展为内置 Elasticsearch、OpenSearch 和 Apache Solr adapter 的能力驱动工作区。

## 主要更新

- 引入版本化 adapter manifest、可选能力合约和能力检查；连接表单可选择 Elasticsearch、OpenSearch 或 Solr。
- renderer 统一使用类型化 `window.searchApi`，并继续兼容读取缺少 `engineType` 的旧 Elasticsearch 连接。
- ES/OpenSearch 共享索引、Mapping、Settings、DSL 查询和维护流程；Solr 使用 Collection/Core、Schema、uniqueKey 和原生查询参数，不强制转换为 ES DSL。
- Solr 支持文档读写、JSON/CSV 导入导出及 commit/softCommit 策略；不展示 Elasticsearch Bulk NDJSON 专属格式。
- 导入导出使用流式解析、有限批次、进度、取消和临时文件清理；修复 Solr 原生 JSON 字段保留与 ES/OpenSearch CSV 文档 ID 还原。
- 加强 IPC 运行时校验、安全错误返回、请求取消与过期响应保护；修复文档 ID 点段的 URL 规范化风险。
- 完整递归提取 ES/OpenSearch 的 nested/object、多字段和 ES 6 typed mapping 元数据。
- 新增 Vitest fixture/contract 回归测试和 Windows/Linux CI；补齐安装器源码跟踪。

安装器脚本现在随源码提交；Windows CI 复用依赖安装得到的 Electron，并从上游获取打包工具，减少对本地镜像配置的依赖。

## 下载与使用

- `SearchDBPad-0.4.0-x64.exe`：Windows x64 安装版，支持选择安装目录。
- `SearchDBPad-0.4.0-portable.exe`：Windows x64 便携版，无需安装。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

包未做 Authenticode 代码签名。已有连接无需手动迁移；卸载时可选择保留应用数据。

## 验证范围与已知限制

- 本地类型检查、254 项单元/contract 测试和生产构建通过。
- Windows NSIS 安装版与 portable 便携版完整打包通过，可执行文件版本资源为 0.4.0；没有跳过资源编辑。便携版单独启动检查未完成，安装/卸载/升级未执行。
- 已验证真实 Elasticsearch 8.6.1 的只读探测、集群/资源列表、文档分页、Mapping 和 Settings；Electron 已检查启动、连接表单、部分加载/空/错误/成功状态和删除确认取消路径。
- Elasticsearch 6.x–9.x、OpenSearch 1.x/2.x、Solr 8/9 是 adapter 目标协议范围，完整真实服务器矩阵尚未完成；fixture 测试不等同于所有版本的 live 兼容性证明。
- 自定义 TLS/代理/证书配置、扩展认证、PIT、可恢复任务和外部插件尚未完整实现。当前支持无认证和 Basic Auth。
- Windows 安装、卸载、升级以及全部引擎的读写/取消/大文件传输仍需进一步验收。
