# SearchDBPad v0.4.1 · 界面精简与主题设置

这是一次界面小更新，让查询和数据工作区获得更多可用空间，并集中管理外观偏好。

## 主要更新

- 移除顶部重复的产品名称、简介和主题按钮，释放 56 px 工作区高度；产品介绍继续通过“帮助 → 关于 SearchDBPad”查看。
- “文件 → 设置”提供浅色、深色、跟随系统三种主题，选择后立即生效，重启后保留。
- 旧版本已保存的浅色/深色偏好继续使用；新用户默认跟随系统，系统外观变化时自动更新应用内容。
- 连接侧栏与五处 Monaco JSON 编辑器同步使用实际主题。
- 项目内补充后续方向和查询工作台讨论草案；草案中的工作台功能仍待讨论，不属于本次已交付能力。

原生菜单与标题栏保持操作系统样式。搜索引擎适配范围和认证模式延续 0.4.0，本次没有新增服务器协议能力。

## 下载

- `SearchDBPad-0.4.1-x64.exe`：Windows x64 安装版。
- `SearchDBPad-0.4.1-portable.exe`：Windows x64 便携版。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256 校验值。

可直接使用已有连接和收藏，无需手工迁移。包未配置 Authenticode 代码签名。
